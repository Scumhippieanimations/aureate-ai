Prompt Guides

Master the art of prompting for cinematic, professional-grade results.

Image
The Cinematography Formula
Subject + setting + lighting + lens + mood + era. Example: "A lone detective, rain-soaked Shinjuku alley, neon backlight, 35mm wide angle, noir melancholy, 1970s film grain"
Video
Motion Language
Always specify camera movement: dolly in / pull back / orbit / static / handheld shake. Motion direction changes everything about the emotional feel of a clip.
Scene
World Layering
Start macro (continent → city → district) then go micro (street → building → room → surface detail). Each layer adds believability to your world.
CGI
The Architecture Trick
Reference real architectural movements (Brutalism, Deconstructivism, Metabolism) for instantly coherent CGI world aesthetics. Architects spent decades on these design languages — borrow them.
